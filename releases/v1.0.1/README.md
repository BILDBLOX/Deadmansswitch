# v1.0.1 prebuilt Windows binaries

Fixes a bug in 1.0.0 where the Settings panel, once opened, could never be
closed — clicking Save, the ✕, the backdrop, or pressing Esc all appeared
to do nothing because a CSS rule kept the panel forced visible regardless
of what the code told it to do. Use this version, not v1.0.0.

Download, then just double-click:

- **`Deadman's Switch Setup 1.0.1.exe`** — one-click installer (Start Menu +
  desktop shortcut, installs per-user, no admin required).
- **`Deadman's Switch Portable 1.0.1.exe`** — no install; run it from
  anywhere, including a USB stick.

Both are unsigned. Windows SmartScreen will likely flag the first run —
click **More info → Run anyway**. See the main [README](../../README.md)
for what the app does and how it's built.
