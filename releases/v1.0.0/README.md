# v1.0.0 prebuilt Windows binaries

No GitHub Releases integration was available when these were produced, so
they're checked in here directly instead. Download, then just double-click:

- **`Deadman's Switch Setup 1.0.0.exe`** — one-click installer (Start Menu +
  desktop shortcut, installs per-user, no admin required).
- **`Deadman's Switch Portable 1.0.0.exe`** — no install; run it from
  anywhere, including a USB stick.

Both are unsigned. Windows SmartScreen will likely flag the first run —
click **More info → Run anyway**. See the main [README](../../README.md)
for what the app does and how it's built.

Built with `electron-builder` from this repo's `claude/deadmans-switch-app-p92117`
branch at this commit.
